# Segurança

Este repositório não deve receber senhas, tokens, arquivos `.env`, strings reais de banco de dados, exportações de dados ou credenciais de colaboradores.

## Relato de vulnerabilidade

Não publique detalhes sensíveis em uma issue pública. Envie o relato diretamente à responsável pelo projeto e inclua:

- descrição do problema;
- passos para reprodução;
- impacto observado;
- versão ou commit afetado;
- evidências sem dados pessoais ou credenciais reais.

Revogue imediatamente qualquer segredo que tenha sido exposto, inclusive se ele tiver sido removido em um commit posterior, porque o histórico do Git pode continuar acessível.
